# مدیریت کد — نسخهٔ چندفایلی و قابل نصب

## ساختار
- `index.html`: اسکلت صفحه‌ها
- `css/styles.css`: استایل‌ها
- `js/app.js`: منطق برنامه و ذخیره‌سازی محلی، ویرایش/حذف ثبت‌ها و انتخاب تاریخ شمسی
- `manifest.webmanifest`: مشخصات نصب به‌صورت PWA
- `service-worker.js`: کش فایل‌های برنامه برای بازشدن آفلاین
- `icons/`: آیکون‌های نصب

## استقرار روی سرور شرکت
1. تمام محتویات این پوشه را بدون تغییر ساختار در یک پوشه روی وب‌سرور قرار دهید.
2. سایت باید از طریق HTTPS ارائه شود (برای نصب PWA و Service Worker؛ در محیط توسعه localhost هم مجاز است).
3. کارکنان صفحه را با مرورگر گوشی باز کنند و از منوی مرورگر گزینهٔ «Install app / افزودن به صفحهٔ اصلی» را انتخاب کنند.
4. داده‌های این نسخه هنوز در حافظهٔ همان مرورگر/گوشی ذخیره می‌شوند. برای جلوگیری از گم‌شدن اطلاعات، فعلاً خروجی پشتیبان JSON را نگه دارید.

## امکانات این نسخه
- هنگام ثبت هر کد یا بازه، تاریخ شمسی از طریق انتخاب سال، ماه و روز تعیین می‌شود و نیازی به تایپ تاریخ نیست.
- در گزارش‌ها و آخرین ثبت‌ها، هر رکورد امکان ویرایش کد، قسمت و تاریخ و همچنین حذف دارد. تعداد هر کد همچنان از بکاپ کارخانه خوانده می‌شود و قابل ویرایش دستی نیست.

## وضعیت ارسال به سرور
این نسخه، فایل‌ها را جدا و پوستهٔ PWA را اضافه می‌کند؛ **ارسال واقعی داده‌ها به سرور و ورود نیرو هنوز پیاده‌سازی نشده است**. دکمهٔ ارسال به سرور در نسخهٔ اصلی همچنان غیرفعال است. برای این مرحله باید API سرور، روش احراز هویت نیرو، و قواعد اعتبارسنجی سمت سرور تعریف شوند. اطلاعات تولید و نرخ‌ها نباید با اتکا به اعتبارسنجی مرورگر به‌تنهایی پذیرفته شوند.

## نکتهٔ مهم دربارهٔ چند دستگاه
`localStorage` فقط برای همان مرورگر/دستگاه است و خودبه‌خود با گوشی یا رایانهٔ مدیر همگام نمی‌شود. همگام‌سازی نیازمند پایگاه داده و API سمت سرور است؛ پنل مدیریت نیز باید از همان API داده بخواند و دسترسی‌اش محدود به مدیران مجاز باشد.
